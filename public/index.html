MINI CASO PRÁCTICO

GitHub + Jira - SCRUM-1

Simulación de un flujo de trabajo donde Jira administra la tarea y GitHub administra el código fuente.

1

Jira

Se crea una tarea para una nueva funcionalidad.

2

GitHub

Se crea una rama usando la clave de Jira.

3

Commit / PR

La clave de Jira se incluye en el commit y Pull Request.

4

Seguimiento

Jira puede mostrar la actividad de desarrollo relacionada.

Crear una tarea directamente en Jira

Esta parte es opcional para la exposición. Requiere configurar las variables de Jira en el archivo .env.

Comandos para demostrar GitHub

git checkout -b DEMO-1-login
git add .
git commit -m "DEMO-1 Implementar pantalla de inicio de sesión"
git push -u origin DEMO-1-login

Reemplaza DEMO-1 por la clave real de tu tarea en Jira.
